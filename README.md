# 🐳 Dockerized CI/CD Automation Pipeline

A production-ready implementation of a containerized Python microservice featuring automated building and testing via GitHub Actions.

## 🚀 Architecture & Features
* **Multi-Stage Docker Build:** Optimizes final container image size by separating build dependencies from the runtime environment.
* **Automated CI/CD:** Uses GitHub Actions to validate code syntax, install dependencies, and test container builds on every push.
* **Lightweight Microservice:** Built using Python Flask with built-in JSON health endpoints.

## 🛠️ Tech Stack
* **Containerization:** Docker, Docker Buildx
* **CI/CD Orchestration:** GitHub Actions
* **Language & Framework:** Python, Flask
